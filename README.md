# Óticas Candiani - Plataforma Web

Este repositório contém o código-fonte da nova plataforma web da **Óticas Candiani**. O projeto foi desenvolvido sob medida para oferecer uma experiência moderna, premium e responsiva aos clientes.

## Sobre o Projeto

A plataforma é uma aplicação Full-Stack construída com **Next.js** (App Router). Ela engloba:
- Uma vitrine/catálogo digital dinâmico.
- Um painel administrativo exclusivo para gestão interna do catálogo.
- Integração direta com WhatsApp para solicitações de orçamento e atendimento facilitado.

Este código é **exclusivo e confidencial**, feito sob medida para a contratante, possuindo direitos reservados sobre o design, componentes e arquitetura da solução.
